**Midnight Ramen** is an original night-shift cooking game set in a tiny lantern-lit ramen bar, drawn in deep indigo and warm amber. Order tickets land on the board, each showing a bowl to build before its countdown bar runs out. Click the pot to boil noodles, click the ingredient stations on the counter (egg, chashu, naruto, scallion, corn, chili) to assemble the bowl, and serve it at the pass when it matches a ticket exactly — tips grow with the time left, and combos multiply your score. Expired tickets cost one of your three lanterns; lose them all, or run out the three-minute shift clock, and the night ends. Tickets arrive faster and recipes grow longer as the shift heats up. Fully offline static files, mouse and keyboard (1–6, N, SPACE, T, P), all art drawn in canvas code and all sounds synthesized with WebAudio — no assets, no libraries, no network.

## Run it
